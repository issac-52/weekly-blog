## 왜 직접 만들었나요?

Velog, Tistory 같은 플랫폼도 좋지만, 디자인과 기능을 내 마음대로 조절하고 싶었습니다.
무엇보다 **직접 만드는 것 자체가 공부**가 된다는 생각이 컸습니다.

## 기술 스택

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Content**: MDX + gray-matter
- **Icons**: Lucide React

## MDX를 선택한 이유

Markdown 안에 React 컴포넌트를 바로 쓸 수 있다는 점이 매력적이었습니다.
나중에 인터랙티브한 코드 예제나 커스텀 컴포넌트를 넣기도 쉽습니다.

```tsx
// 이런 식으로 코드 블록도 깔끔하게 표시됩니다
export default function Hello() {
  return <h1>Hello, World!</h1>;
}
```

앞으로 꾸준히 글을 올릴 예정입니다.
