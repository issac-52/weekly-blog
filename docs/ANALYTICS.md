# 방문 통계

관리자 `/admin` 상단에 오늘의 블로그가 표시됩니다.

- 오늘 페이지 조회: 홈·지난 호·발행 글 상세의 페이지 이동 수.
- 오늘 방문 브라우저: 같은 익명 쿠키를 사용하는 브라우저를 한국 날짜 하루에 한 번 집계. 실제 사람 수는 아닙니다.
- 오늘 글 조회: 발행된 기사 상세 조회만 집계.
- 최근 30일 조회, 7일/30일 일별 추이, 같은 기간 인기 글 5개.

필수: `supabase/migrations/202610270003_analytics.sql` 적용, `ANALYTICS_SECRET`에 32자 이상 임의 값 설정, `ANALYTICS_ENABLED=true`. 수집은 `SITE_VISIBILITY=public`일 때에만 시작합니다. 비공개 미리보기와 로그인한 관리자 접속은 집계하지 않습니다. 과거 방문 기록은 소급 생성하지 않습니다.

동일 이벤트 UUID 재전송은 중복 집계하지 않습니다. 일반 새로고침은 새 페이지 조회로 집계합니다. 한 익명 브라우저의 분당 최대 30회 제한과 알려진 봇 사용자 에이전트 필터를 적용하지만, 악의적 통계 조작이나 모든 봇을 식별하는 시스템은 아닙니다.

방문 식별에는 무작위 30일 HttpOnly 쿠키를 사용합니다. 원본 쿠키 값은 DB에 보내지 않고 한국 날짜별 HMAC 해시만 저장합니다. 앱 DB에는 IP·원본 사용자 에이전트·리퍼러를 저장하지 않습니다. 날짜가 바뀌면 식별 해시도 달라집니다. 쿠키 차단/삭제, 기기 변경, 추적 차단 등으로 수치가 달라질 수 있습니다. 90일을 넘은 원시 이벤트는 새 조회 수집 시 최대 250건씩 정리합니다. 접속이 없으면 정리도 다음 수집 시점까지 미뤄집니다.

통계 조회 RPC와 원시 이벤트 테이블은 service_role만 접근하며 관리자 API가 별도로 로그인/이메일 권한을 확인합니다. 독자·ChatGPT 초안 연결에는 통계/원시 식별자 읽기 권한을 주지 않습니다. 화면으로 보내는 값은 집계 결과뿐입니다. 기본 콘텐츠 백업에는 통계 원시 이벤트를 넣지 않습니다.
